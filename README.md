# 📣 PR Desk: PIR®'s Public Relations Committee helpdesk

> 🌐 **Portal:** https://psychedelicsinrecovery.github.io/pr-desk-public/ · 💬 **In Discord:** type `/pr` · 📨 **No Discord?** [Web helpdesk](https://psychedelicsinrecovery.github.io/alex-desk-public/portal.html)

**Social, press, brand assets, De Vine News.** PR Desk is where members of **Psychedelics In Recovery™ (PIR®)** ask the Public Relations Committee for help. Every
request becomes a private ticket that a trusted servant claims, works on and resolves, so nothing gets lost in a
group chat.

## 🧭 What this desk handles
- Social media, press and outreach requests
- Brand assets: logos and PIR® / Psychedelics In Recovery™ usage
- De Vine News newsletter (PR subcommittee) and the podcast and A/V team

## 🎫 How a ticket works
1. **Open it:** type `/pr` anywhere in [PIR®'s Discord](https://discord.gg/MyprTq8w95) and fill in the short form, or use the
   [web helpdesk](https://psychedelicsinrecovery.github.io/alex-desk-public/portal.html) with a one-time email link (no password, no account).
2. **A private thread opens** that only you and the Public Relations Committee can see. Your ticket gets an ID like `PR-12`.
3. **Someone claims it** and you'll see its status move: 🆕 new → 🙋 claimed → 🛠️ in progress → ✅ resolved.
4. **Resolved tickets are archived.** Still need help? Tap **Reopen** in the thread.
5. **Check status any time** with `/ticket PR-12` in Discord, or under *My tickets* on the web desk.

## 🔒 Privacy
- Tickets are tracked in a **private** repository. Requesters appear only as a scrambled tag, never a Discord ID or an email address.
- A.L.E.X. (the helper that runs the desks) only sees what you type into its forms and stores no chat history.
- Please don't share passwords or sensitive personal details in a ticket.

## 🛠️ About this repository
This repository publishes the desk's **public portal** on GitHub Pages. It's generated from PIR®'s private desk
repository by the Tech Committee's build (`alex-desk/site/build.py`), so changes are made there and published here
automatically. Ideas or corrections? Open a ticket with `/techcom`.
